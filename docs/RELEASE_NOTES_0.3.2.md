# PC Mode Switcher v0.3.2

## 変更内容

- モードカードの［削除］を、設定を残したまま画面から外す［非表示］へ変更
- 意味が分かりにくかった上下矢印を廃止し、実物大の半透明カードが掴んだ位置のままマウスへ追従するドラッグ操作で表示順を変更・保存できるよう改善
- 新しく追加する最初の6モードへ、既存と同じデザインの午・未・申・酉・戌・亥アイコンを追加

- 画面右上に、Windowsで現在入力先に選ばれているマイクを直接ON・OFFできるボタンを追加
- アプリ操作中はマイクの実際の状態を定期的に再確認し、表示を自動更新
- 設定メニューに、マイク関連の表示と操作をまとめて無効にする項目を追加
- モード適用が一部だけ失敗した場合も、反映済みのWindows設定から「現在のモード」を更新
- 外部から不正なプログラムを読み込む危険を減らすため、Windowsのシステムフォルダーだけを参照するように改善
- アプリの動作基盤を.NET 8から.NET 10へ更新

## 更新方法

v0.3.1から実行ファイルを置き換えるだけで更新できます。保存済みのモード設定はそのまま引き継がれます。.NETの追加インストールは不要です。
