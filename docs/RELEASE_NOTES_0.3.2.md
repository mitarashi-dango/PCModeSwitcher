# PC Mode Switcher v0.3.2

## 変更内容

- 画面右上に、Windows側の既定マイクを直接ON・OFFできるボタンを追加
- アプリ操作中はマイクの実際の状態を定期的に再確認し、表示を自動更新
- 設定メニューに、マイク関連の表示と操作をまとめて無効にする項目を追加
- モード適用が一部だけ失敗した場合も、反映済みのWindows設定から「現在のモード」を更新
- DLLの検索先をWindowsのSystem32に固定し、安全性を強化
- 実行基盤を.NET 8から.NET 10へ更新

## 更新方法

v0.3.1から実行ファイルを置き換えるだけで更新できます。保存済みのモード設定はそのまま引き継がれます。.NETの追加インストールは不要です。
