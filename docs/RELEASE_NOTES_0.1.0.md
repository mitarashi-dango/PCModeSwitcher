# PC Mode Switcher v0.1.0

最初の配布版です。

## 主な機能

- GAME / WORK / NORMALの3モードをワンクリックで適用
- 画面OFF時間、スリープ時間、電源プランをモードごとに保存
- AC電源接続時とバッテリー駆動時を個別に設定
- 右上の閉じるボタンで通知領域へ格納するか終了するかを選択可能
- 通知領域へ格納した際の通知を有効・無効から選択可能
- 通知領域アイコンのダブルクリックで画面を再表示
- 通知領域アイコンの右クリックメニューから完全終了
- 多重起動を防止し、起動済みの画面を前面へ復元
- 設定を次回起動後も保持

## 安全性

- 管理者権限を要求しません。
- Windowsの標準機能を使用し、電源設定の保存場所を直接書き換えません。
- 利用できない電源プランは適用しません。
- 設定変更が途中で失敗した項目は変更前の値へ戻します。

## 注意事項

- Windows 11 x64向けです。
- 配布ファイルはコード署名されていないため、初回起動時にSmartScreenの警告が表示される場合があります。
