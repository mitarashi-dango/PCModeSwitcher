# PC Mode Switcher v0.2.0

通知領域からの操作と常駐利用を強化したリリースです。

## 新機能

- Windowsログイン時の自動起動を設定可能
- 自動起動時は画面を開かず通知領域で起動
- GAME / WORK / NORMALを直接適用するグローバルショートカットを設定可能
- 通知領域の右クリックメニューから各モードを直接適用
- 通知領域メニューで現在適用中のモードをチェック表示
- 通知領域またはグローバルショートカットから切り替えた結果を通知

## 改善

- ショートカットの重複、Windows予約キー、他アプリとの競合を検出
- 以前の設定ファイルへ自動起動・ショートカットの既定値を安全に補完
- 閉じる動作が「アプリを終了」でも、自動起動直後は通知領域から画面を復元可能

## アップデート

v0.1.0から実行ファイルを置き換えるだけで更新できます。保存済みのモード設定はそのまま引き継がれます。グローバルショートカットは既定ですべて未設定です。

## 注意事項

- Windows 11 x64向けです。
- 管理者権限は不要です。
- 配布ファイルはコード署名されていないため、初回起動時にSmartScreenの警告が表示される場合があります。
