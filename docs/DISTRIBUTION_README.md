# PC Mode Switcher 0.2.0

Windows 11の画面OFF時間、スリープ時間、電源プラン、既定マイクのミュート状態を、GAME / WORK / NORMAL / CUSTOM1〜6の9モードとしてまとめて切り替えるアプリです。アプリ画面には好きな1〜5モードを表示できます。

## 動作環境

- Windows 11（64ビット）
- 管理者権限は不要
- .NETの追加インストールは不要

## 使い方

1. ZIPを任意のフォルダーへ展開します。
2. `PCModeSwitcher.exe` を起動します。
3. 表示中のモードから使いたいものの「適用」を押します。
4. 各モードの設定を変える場合は「編集」を押します。マイクは「変更しない」「ミュート」「ミュート解除」から選択でき、既定では変更しません。

バッテリーを搭載していないPCでは、バッテリー用の画面OFF・スリープ設定は自動的に表示されなくなり、適用対象にもなりません。

初期状態ではGAME / WORK / NORMAL / CUSTOM1 / CUSTOM2を表示します。「設定」で全9モードから好きな1〜5モードを選べます。右上の閉じるボタンを押すと通知領域へ格納されます。通知領域のアイコンをダブルクリックすると再表示でき、右クリックメニューからは全9モードの直接適用と完全終了ができます。現在適用中のモードにはチェックが付き、通知領域から切り替えた結果は通知されます。この動作と格納時の通知も「設定」で変更できます。

「設定」では、Windowsログイン時の自動起動と、各モードを直接適用するグローバルショートカットも設定できます。自動起動時は画面を開かず通知領域で起動します。ショートカットはアプリが通知領域にある間も使用でき、既定ではすべて未設定です。

アプリをもう一度起動した場合は新しい画面を増やさず、すでに起動している画面を表示します。

## 設定の保存場所

設定は次のファイルへ自動保存されます。

```text
%LOCALAPPDATA%\PCModeSwitcher\settings.json
```

アプリを更新するときは、新しいZIPを展開して `PCModeSwitcher.exe` を置き換えてください。保存済みの設定はそのまま引き継がれます。

## Windowsの警告が表示された場合

この配布版にはコード署名がないため、ダウンロードしたファイルの初回起動時にWindows Defender SmartScreenの警告が表示される場合があります。入手元が公式GitHubリポジトリであることを確認したうえで実行してください。

## アンインストール

通知領域のアイコンを右クリックして「終了」を選び、展開したフォルダーを削除します。保存済みの設定も消す場合は、上記の設定ファイルを含む `%LOCALAPPDATA%\PCModeSwitcher` フォルダーを削除してください。

## 安全性

- 電源設定の変更にはWindows Power APIだけを使用し、電源設定のレジストリ値を直接編集しません。
- マイクのミュート変更にはWindows Core Audio APIを使用し、既定の録音デバイスだけを対象にします。
- Windowsログイン時の自動起動を有効にした場合だけ、現在のユーザーの `Run` キーへ起動情報を登録します。無効にすると削除します。
- 利用可能な電源プランだけを適用します。
- 画面OFFまたはスリープの設定変更が途中で失敗した場合は、その項目を変更前の値へ戻します。
