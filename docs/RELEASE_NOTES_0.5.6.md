# PC Mode Switcher v0.5.6

## 変更内容

- 対象モニターを選択したときに、表示設定画面が連続してエラーを表示した後に終了する問題を修正
- モード編集をキャンセルしたときに、編集中の内容が元の設定へ残らないよう修正
- GAMEモードのⅡコンを専用画像として表示し、メイン画面・設定画面・モード編集画面・ショートカット・通知領域で統一
- Ⅱコンの十字キーとマイク穴を整え、アイコンの見た目を改善
- 追加モードの十二支アイコンをモード編集画面でも画像として表示し、枠内へ収まるよう調整
- モード編集画面を小さい作業領域でも開きやすいサイズへ調整

## 更新方法

v0.5.5から実行ファイルを置き換えるだけで更新できます。保存済みのモード設定はそのまま引き継がれます。.NETの追加インストールは不要です。
