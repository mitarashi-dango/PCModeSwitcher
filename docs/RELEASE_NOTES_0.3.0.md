# PC Mode Switcher v0.3.0

モード構成とWindows設定との連携を拡張し、日常的な切り替えを分かりやすくしたリリースです。

## 新機能

- CUSTOMをCUSTOM1へ移行し、CUSTOM1〜6までの6モードを追加
- 全9モードから、アプリ画面に表示する1〜5モードを選択可能
- 各モードに「変更しない」「ミュート」「ミュート解除」のマイク設定を追加
- 実際のWindows電源設定から現在のモードを自動判定
- 通知領域の各モードへマウスを重ねると、画面OFF、スリープ、電源モード、適用時のマイク設定を表示

## 改善

- CUSTOM1〜6のアイコンを、子・丑・寅・卯・辰・巳を表す統一された白黒デザインへ変更
- バッテリー未搭載PCではバッテリー用設定を画面から隠し、適用対象からも除外
- モード編集後、通知領域の説明を即時更新
- 現在のアプリバージョンを画面へ表示

## アップデート

v0.2.0から実行ファイルを置き換えるだけで更新できます。旧CUSTOMの電源・マイク・ショートカット設定はCUSTOM1へ引き継がれます。CUSTOM2〜6は既定値で追加されます。

## 注意事項

- Windows 11 x64向けです。
- 管理者権限は不要です。
- 配布ファイルはコード署名されていないため、初回起動時にSmartScreenの警告が表示される場合があります。
