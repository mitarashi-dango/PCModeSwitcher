# PC Mode Switcher v0.5.5

## 変更内容

- ［ヘルプ］メニューに、Ko-fiで開発を一度だけ応援できる導線を追加
- 支援ページは外部ブラウザで開き、アプリが決済情報を取得・保存しない設計にしました
- GAMEモードのアイコンを、メイン画面・設定画面・ショートカット画面・通知領域でⅡコンのデザインに統一
- 通知領域のモード一覧をメイン画面と同じ順番に統一
- スピーカー音量、画面のリフレッシュレート、アプリの起動・終了、ウィンドウ配置をモードごとに切り替えられる高度な設定を追加
- 診断画面とログ出力を追加し、設定切り替えに失敗したときの原因を確認しやすく改善
- 日本語、英語、繁体字中国語の表示切り替えに対応
- 追加モード用のアイコンを12種類に拡充
- 表示言語の変更時に、通知領域のモード一覧更新でエラーが出る問題を修正
- モードの追加・編集を保存できなかった場合、未保存の内容を画面やメモリに残さないよう修正
- 予期しないエラーの詳細をログへ記録し、外部ブラウザを開けない場合は専用メッセージを表示

## 更新方法

v0.3.2から実行ファイルを置き換えるだけで更新できます。保存済みのモード設定はそのまま引き継がれます。.NETの追加インストールは不要です。
