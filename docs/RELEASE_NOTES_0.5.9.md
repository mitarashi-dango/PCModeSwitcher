# PC Mode Switcher v0.5.9

## 変更内容

- 表示言語にアラビア語とヒンディー語を追加
- アラビア語表示で画面全体を右から左へ配置するよう対応
- モード適用後の［元に戻しますか？］を10秒間強調し、30秒後にメイン画面から非表示にするよう変更
- 30秒後も［モード］メニューの［モード適用前の状態に戻す］、または通知領域から復元できるよう改善
- アラビア語、ヒンディー語を含む各言語の表現を調整

## 更新方法

v0.5.8から実行ファイルを置き換えるだけで更新できます。保存済みのモード設定はそのまま引き継がれます。.NETの追加インストールは不要です。
