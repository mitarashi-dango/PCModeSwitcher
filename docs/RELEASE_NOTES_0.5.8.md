# PC Mode Switcher v0.5.8

## 変更内容

- 表示言語に簡体字中国語、スペイン語、実験的なエスペラントを追加
- ［ヘルプ］メニューに手動の更新確認を追加し、新しいバージョンがある場合だけ控えめに通知するよう変更
- 新しいバージョンの自動確認を追加（設定から無効化可能）
- モード変更時に起動したアプリの情報取得が一時的に失敗しても追跡を続け、復元時にアプリが残ったまま成功扱いになる問題を修正
- ウィンドウの高さが低い場合でも、モードカード下部の操作ボタンまでスクロールできるよう修正
- 設定のインポート／エクスポートで、自然な初期フォルダーを開くよう改善

## 更新方法

v0.5.7から実行ファイルを置き換えるだけで更新できます。保存済みのモード設定はそのまま引き継がれます。.NETの追加インストールは不要です。
