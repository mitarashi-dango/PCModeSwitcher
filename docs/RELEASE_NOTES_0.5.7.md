# PC Mode Switcher v0.5.7

## 変更内容

- モード適用後の［元に戻しますか？］を30秒間だけ強調し、その後は控えめに表示するよう変更
- アプリ終了時の復元確認を廃止し、適用したモード設定を維持したまま即座に終了するよう変更
- 次回起動時には、正常に適用済みの復元記録を確認なしで破棄するよう変更
- モード適用中にアプリやWindowsが終了した場合は、次回起動時に確認せず自動復旧するよう変更
- 自動復旧に失敗して人の対応が必要な場合だけ警告するよう変更

## 更新方法

v0.5.6から実行ファイルを置き換えるだけで更新できます。保存済みのモード設定はそのまま引き継がれます。.NETの追加インストールは不要です。
